추상클래스, 왜 사용할까?

코딩 지식2026. 2. 16.읽는 데 5분

자바를 공부하다 보면 한 번쯤 들게 되는 의문입니다. "추상클래스는 왜 사용하는 거지? 그냥 일반 클래스를 상속받아서 오버라이딩하면 되는 거 아닌가?"

추상클래스의 핵심 목적

이론적으로는 "구현을 강제한다"고 배우지만, 실제로 일반 클래스로도 똑같은 결과를 만들 수 있습니다. 하지만 실무 관점에서 보면 추상클래스는 다음과 같은 이유로 필요합니다.

불완전한 객체 생성을 막는다 — 공통 로직은 부모가, 반드시 필요한 구현은 자식에게 강제한다.
C · inorder.cCOPY
// 중위 순회 (Inorder)
void inorder(TreeNode *node) {
    if (node == NULL) return;
    inorder(node->left);         // 왼쪽 자식
    printf("%d ", node->data);  // 루트
    inorder(node->right);        // 오른쪽 자식
}

위 코드처럼 반드시 구현해야 하는 로직이 있을 때, 추상클래스는 컴파일 시점에 실수를 잡아줍니다. 코드 블록은 다크 테마로 본문과 대비되어 가독성을 높입니다.

  • 공통 로직 재사용 + 구현 강제
  • 설계 의도를 코드로 표현
